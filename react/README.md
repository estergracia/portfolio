# Portfolio (React + Tailwind CSS v4 + Vite)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in /dist

- All content (name, links, experience, case studies, stack) is at the top of `src/App.jsx`.
- Colors for dark and light mode are tokens at the top of `src/index.css`.
- The theme button follows the system setting first, then remembers the visitor's choice.
- Links set to "#" are placeholders.

`tools/build_preview.py src out.html` builds a single-file browser preview from the same source.
